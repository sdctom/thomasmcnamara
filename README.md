# Thomas J. McNamara website

Static HTML/CSS website hosted by GitHub Pages at https://thomasmcnamara.me/.

## Edit website text

Open https://thomasmcnamara.me/editor.html and select a heading or paragraph. TinyMCE provides formatting and link editing while retaining the page layout.

1. Edit text and save a draft in your current browser.
2. Preview the website and download `index.html`.
3. Sign into GitHub and upload the downloaded file to this repository's root, replacing `index.html`. Ensure the browser has not renamed it to `index (1).html`.
4. Commit the change, wait for the Pages deployment to succeed in Actions, and check the live website.

Draft saving is local to the current browser/device and does not publish. The editor page is public; publishing requires authorized GitHub access. No GitHub credentials belong in the editor source.

Tiny Cloud must allow the website domain. The Tiny Cloud browser key is intentionally public. PowerPaste uses the supplied trial entitlement; remove that plugin if the entitlement ends to retain core editing.

If the editor URL returns 404, check the latest Pages deployment. Tiny Cloud domain approval does not publish the HTML file.
